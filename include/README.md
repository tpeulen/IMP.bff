Public headers, laid out by theme: `include/<theme>/X.h` is reached as

     #include <IMP/bff/<theme>/X.h>

and `include/<theme>.h` (generated by `tools/dev/theme_layout.py`) includes
every header of one theme as `<IMP/bff/<theme>.h>`. The themes are listed in
`src/Themes.cmake`; `include/imp/` is the connection layer to IMP and
`include/internal/` holds private helpers. A header goes into the theme of the
source that implements it (`test/test_theme_headers.py`), and there are no
forwarding headers at old paths: an include names the themed path.

IMP's module tooling links only `include/*.h` and `include/internal/*.h`
into its build tree; `cmake/ThemeHeaders.cmake` links the themed directories
beside them. All headers include `IMP/bff/bff_config.h` first and put their
code between `IMPBFF_BEGIN_NAMESPACE` and `IMPBFF_END_NAMESPACE`. Python
bindings are in `pyext/include/*.i`.
