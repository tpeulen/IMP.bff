Detailed Description

A continuous-time Bayesian network: variables, arcs, one CIM per variable.

aGrUM's CTBN. Arcs may form cycles (a CTBN allows them: a conformation that gates a dye's quenching, and a dye state that gates a photo-isomerisation). The joint generator amalgamates the CIMs in declaration order, so the first variable added is the most significant digit of the joint index.

A scheme with two clocks – spontaneous rates and excitation-scaled rates, K = K_dark + k_exc K_exc in FCS.h, k_nrad / k_rad in tttrlib's simulator – is two networks over the same variables: amalgamation is linear in the rates, so the joint generators add.
