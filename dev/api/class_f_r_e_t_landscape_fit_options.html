◆ precondition

bool FRETLandscapeFitOptions::precondition = true

Precondition each block with the Laplace precision (empirical Fisher information plus prior precision) at its start point. The parameters differ in scale by orders of magnitude, and without this L-BFGS with a short history crawls.

◆ precondition_damping

double FRETLandscapeFitOptions::precondition_damping = 1.0

Added to the diagonal of that precision (per unit of theta squared), so that directions the photons do not constrain take bounded steps.
