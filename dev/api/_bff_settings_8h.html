IMPBFFEXPORT SequenceSearchSettings get_sequence_search_settings ( const std::string & path = "")

The sequence_search section of the settings file at path, or of get_settings_path when path is empty.

A missing file or section gives the defaults. Relative database and index paths are taken relative to the settings file.

Exceptions
ValueExceptionon invalid JSON or an unknown key in the section
