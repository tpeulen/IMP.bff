Detailed Description

Per-site rates and conservation scores of the reference sequence.

One entry per column in which the reference has a residue, in alignment order. Scores and interval bounds are normalised (mean 0, sample standard deviation 1 over these positions); the standard deviation is divided by the same scale. The raw getters return the rates before normalisation.
