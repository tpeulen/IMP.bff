Repack a protein's side chains to the global-minimum-energy conformation.

Reads pdb_in (backbone N, CA, C, O required per residue; any side chains present are ignored), repacks every rotatable side chain, and writes the result to pdb_out with the residue numbering and ordering preserved. The search is deterministic: two calls on the same input and library give identical coordinates.

Parameters
[in]pdb_inthe input backbone PDB
[in]pdb_outwhere the repacked PDB is written
[in]rotamer_librarythe Dunbrack-2010 library – either FASPR's binary dun2010bbdep.bin or a .drot.pto container carrying it, which is unpacked to a scratch copy because the engine seeks in that file by byte offset
[in]verboseecho the packing log to stdout
Exceptions
IOExceptionwhen the input or the library cannot be read
std::runtime_erroron a fatal packing error – an incomplete backbone, an unknown library layout

The algorithm is FASPR (Huang, Pearce & Zhang, Bioinformatics 2020;36:3758-3765, MIT, github.com/tommyhuangthu/FASPR): CHARMM19 van der Waals, hydrogen bonds, disulfides and a rotamer prior, minimised by DEE-Goldstein and DEE-split elimination and then tree decomposition. It is vendored in src/internal/ProteinSidechainFaspr*.{h,cpp}, which carry the original notice, and pinned against the reference executable by test/faspr/test_faspr_port.py.

The quenching centres one residue reaches over its side-chain rotamers.

The backbone angles phi and psi are measured on the structure (a residue is bonded to its neighbour in the same chain when the C-N distance is below 1.8 A; a chain end or a break takes -60 and -45 degrees), the library is read at them (read_protein_sidechain_dunbrack_rotamers, its default cuts), and every rotamer is built from the crystal side chain by turning chi1 about CA-CB and chi2 about CB-CG (higher chi keep their crystal values). A rotamer is dropped when any of its side-chain atoms beyond CB comes within clash of an atom of another residue (heavy atoms are what the caller passes). The kept rotamers' probabilities are renormalised; when none is kept the crystal centre is the ensemble.

Placed: CYS SER THR VAL (chi1), MET TRP TYR PHE HIS LEU ILE ASP ASN GLU GLN LYS ARG (chi1, chi2). Anything else (PRO, ALA, GLY, a ligand) is its crystal centre.

Parameters
[in]chains,res_ids,res_names,atom_namesone per atom
[in]coordsflat, three per atom
[in]chain,res_idthe residue
[in]library_patha container written by write_protein_sidechain_dunbrack_library (IMP.bff ships one, get_data_path("rotamer_library")/sidechains.drot.pto)
[in]quench_atomsthe atom names whose centroid is the centre
[in]clashAngstrom
Exceptions
ValueExceptionwhen the residue is not in the structure or has none of quench_atoms

The rotamers of residue at backbone angles (phi, psi).

Reads that residue's object and no other. The two cuts are FASPR's own defaults, applied in FASPR's order: rotamers come sorted by probability, the first one below probability_min ends the list, and the list also ends once the accumulated probability passes probability_accumulated. Pass 0 and 1 to take the bin whole.

Parameters
[in]patha container written by write_protein_sidechain_dunbrack_library
[in]residueone-letter code; A and G have no rotamers
[in]phi,psidegrees
Exceptions
ValueExceptionfor a residue this library does not carry

IMPBFFEXPORT void write_protein_sidechain_dunbrack_library ( const std::string & bin_path,
const std::string & path )

Convert FASPR's dun2010bbdep.bin into a .drot.pto container.

Writes one rot.bbdep.records object per amino acid – that residue's records exactly as they lie in the binary – plus a rot.bbdep.header describing the bin scheme, the record layout and the library's provenance, and a drot.catalog naming the residues. Each object is compressed independently with Zstd level 3. Readers also accept existing Brotli-compressed containers.

Parameters
[in]bin_pathFASPR's dun2010bbdep.bin
[in]paththe container to write
Exceptions
IOExceptionwhen the binary is missing or is not the expected size
