Detailed Description

The shape of a grid: extent, spacing and where its corner sits.

A stand-in for the handful of IMP::em::DensityHeader fields this module ever touched. Everything an EM header also carries – the cell angles, the map statistics, the axis order – is absent because nothing here read it.

Cereal, because PathMapHeader holds one of these and serializes it.

Eleven numbers. The IMP::em::DensityHeader this replaced wrote about forty – cell angles, axis order, microscope voltage, defocus – none of which a path-search lattice ever had a value for. That does mean a PathMapHeader pickled by an older build will not load into this one: the archive is a different shape, and it is not versioned.
