Detailed Description

A labelled crosstalk matrix: sources as rows, detectors as columns.

The one type both crosstalk matrices share — an excitation matrix and an emission matrix are the same thing at different ends of the light path, and giving them one definition is what stops a payload built by one tool and consumed by another from agreeing on nothing but the shape.

The values are row-major, values[i * n_columns() + j] the contribution of row i to column j. Labels name the rows and columns; \select re-orders and sub-samples against them, filling a requested-but-missing label with zeros.
