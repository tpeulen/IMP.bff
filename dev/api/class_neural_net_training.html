◆ get_quantized_network()

const MsgpackBytes & NeuralNetTraining::get_quantized_network ( ) const
inline

FP4 training: the bff.quantized_neural_net msgpack document of the trained network in its training format – FP4 layers with exactly the weights the forward pass used (2-D scaled) and FP4 activations (W4A4), the kept layers in float64 – so QuantizedNeuralNet.from_msgpack(get_quantized_network()) evaluates what training evaluated. Empty for float64 training. get_network() is the float64 master weights in either case.
