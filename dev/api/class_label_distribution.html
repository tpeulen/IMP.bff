Detailed Description

Where a dye is, as something that produces states on demand.

Two of them: an accessible volume computed from a structure's obstacles, and an isotropic Gaussian that needs no structure at all. They exist so a caller can hold a label and ask it for states, without deciding which model produced them.

The volume is computed lazily, on the first call to #IMP::bff::LabelDistribution::get_accessible_volume, because building one is the expensive thing a label does and a caller often holds several before asking any of them anything.
