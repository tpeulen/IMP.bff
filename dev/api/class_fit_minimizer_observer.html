Detailed Description

What a caller is told while a minimisation runs, and how it stops one.

A SWIG director, so a Python caller – a GUI progress dialog, most of the time – subclasses it and overrides report(). This is the same shape RRTCollision uses for the growth loop: the C++ loop asks, the Python subclass answers.

report() is called once per residual evaluation. Returning false cancels the run, which is how chisurf's OptimizationCancelled travels without an exception having to cross the boundary in the middle of a Fortran-shaped loop. The optimiser then stops at the last accepted parameter vector – not the trial point it was evaluating – so a cancelled fit leaves the model somewhere it has actually been.
