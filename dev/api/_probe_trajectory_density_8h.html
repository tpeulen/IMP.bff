The name an analysis gives an atom particle.

With a lookup (site serial -> name, from the system CIF): the name of the atom's input index, or of the index plus one. Otherwise the atom type without its HET: prefix, or the particle name for a particle that is not an atom. A slash-separated name keeps its last part.
