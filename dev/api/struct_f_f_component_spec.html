Detailed Description

One component of a system to build: a MOL2, its template, and its role.

The typed form of the {"name": ..., "mol2": ..., "template": ..., "role": ...} object the JSON builder takes. It exists so a caller says what it means in C++ instead of composing JSON by hand.
