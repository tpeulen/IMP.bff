Detailed Description

One recorded run: the frames, and what was known at each of them.

The same record for every simulation. potential_energy and kinetic_energy are empty where the simulation has no such quantity – a grid walk has neither – rather than filled with a polite zero, so that a caller can tell "not measured" from "measured and small".
