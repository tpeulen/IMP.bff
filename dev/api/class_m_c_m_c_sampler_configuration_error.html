Detailed Description

Raised for a misconfigured sampler (no objective, fixed ports, a degenerate ensemble, an unknown algorithm...).

std::domain_error so the wrapper maps it to a ValueError – the contract chisurf's samplers raise under. GraphLinkCycleError (GraphPort.h) derives domain_error for the same reason: IMP's wrapper handler maps it to IMP.ValueException, a ValueError, which is what chinet's and chisurf's callers catch.
