Detailed Description

The identity half of chinet's GraphObject: a name and a uid.

chinet's GraphObject also carries a document dict and database registration; those are not ported – GraphSession writes documents from the objects' own state, and there is no registry. What persistence needs beyond the runtime's name and uid is the precursor and death document fields, which live here so they follow the object across sessions exactly as chinet's document did.
