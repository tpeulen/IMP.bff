Detailed Description

template<typename T = double>
struct BayesianLogitTransform< T >

Bounded quantities: x = lo + (hi - lo) sigmoid(z).

log|dx/dz| = log(hi - lo) + log sigmoid(z) + log sigmoid(-z), written through logsigmoid rather than as log(s (1 - s)) because the latter underflows to -inf for |z| beyond about 37 while the former stays accurate: log sigmoid(z) = -log1p(exp(-z)) for positive z and z - log1p(exp(z)) for negative.
