One ensemble per fps.json position that names a rotamer library.

A position's rotamer_library (or library_name / libname / library) field selects the library; library_map, keyed by position name, overrides it or supplies one for a position that names none – which is how an AV-only fps file is screened as rotamers. Positions with neither are skipped rather than guessed at.

The structure is read once and each library at most once, however many positions share them.

Parameters
[in]fps_jsonthe fps.json path
[in]structurethe PDB the positions refer to
[in]library_mapposition name -> library name
[in]optionsthe screening parameters, for every position alike
[in]frame_indexwhich model of a multi-MODEL PDB
