Detailed Description

A callback-free finite problem, useful for persisted/pre-scored graphs.

This is also the executable contract fixture for the SWIG surface. Real fitting adapters subclass ModelSearchProblem in C++ and keep their heterogeneous model states behind the same opaque keys.
