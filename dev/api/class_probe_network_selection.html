Detailed Description

Greedy selection of a probe network by a weighted sum of term losses.

Each step adds the unit (a pair, or in site mode a labelling site with every pair it completes) that minimises

the weighted sum of the terms' losses. A weight of 0 turns a term off; it is still reported. Ties go to the lowest index, as in #IMP::bff::select_probe_pairs.

Site mode needs set_pair_sites. A pair is implied once both of its sites are chosen, a homotypic pair (i, i) as soon as i is (homo-oligomers, as #IMP::bff::select_probe_positions); #IMP::bff::ProbeOligomerPairs builds these rows for any number of protomers. In pair mode the sites, when set, are passed to the terms so the labelling term sees them.
