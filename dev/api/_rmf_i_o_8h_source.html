18// RMF is optional (PRD-139), and opt-*out*: every build has it unless one
19// says otherwise, so IMP's own tooling -- which knows nothing of this flag --
20// keeps building what it always built. It is one file and four functions,
21// called from `bin/imp_bff` and nowhere in the library, and it costs a wheel
22// dearly: librmf pulls Boost.Iostreams, which as packaged (conda and
23// Homebrew alike) pulls Boost.Regex and all of ICU -- some 40 MB against
24// 3 MB of library. Without RMF the four declarations below are not made, so
25// a caller finds out at compile time rather than at link time.
