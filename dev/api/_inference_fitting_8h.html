Fit the mode of an evaluable graph from theta0.

Stops when the decrement is below tolerance (then converged), when a step is not accepted (converged if the last decrement was below 1e-3, as bayesian_decay_fit_node decides), or after max_iterations.

fixed names variables held at their theta0 values (PRD-156 D1). The steps and the Laplace evidence then run over the free coordinates only, so with a hyperparameter held (e.g. the P-spline weight log10_lam) laplace_evidence is log p(y | hyperparameter) – what a user's hyperparameter loop weights by. at_mode keeps the full gradient and information. With fixed empty the result is the one of a fit without the argument, bit for bit.

Exceptions
std::domain_errorif the graph is not evaluable
std::invalid_argumentfor an unknown variable in fixed, or if nothing is free
