Fit the mode of an evaluable graph from theta0.

Stops when the decrement is below tolerance (then converged), when a step is not accepted (converged if the last decrement was below 1e-3, as bayesian_decay_fit_node decides), or after max_iterations.

std::domain_errorif the graph is not evaluable
