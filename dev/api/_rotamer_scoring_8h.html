Compute Boltzmann weights for a rotamer ensemble against a protein.

The end-to-end scorer: builds the hydrogen/backbone/site masks from the atom and residue names, assembles the per-pair Lorentz-Berthelot parameters, calls the all-pairs steric/electrostatic kernel, and returns normalised Boltzmann weights multiplied by the library's own.

Parameters
[in]rotamer_coordsflat, n_rotamers * n_probe_atoms * 3
[in]protein_coordsflat, n_protein_atoms * 3
[in]protein_atom_names,protein_resnamesone per protein atom
[in]rotamer_atom_namesone per dye atom
[in]positive,negativethe dye's charge selectors (its metadata's positive/negative), used only when electrostatic
[in]rotamer_resnamesone per dye atom, or empty
[in]protein_residue_indices,protein_chain_idsone per protein atom, or empty – what the site is resolved against
[in]site_residuethe labelled residue number, or -1 for none
[in]site_chainthe labelled residue's chain; empty matches any
[in]rotamer_weightsthe library's own per-rotamer populations, or empty for uniform
[in]temperaturein K
[in]ignore_hmask hydrogens out of the steric term
[in]electrostaticadd the Debye-Hueckel term from the charges
[in]potential"lj" or "gauss"
[in]sigma_scaling,epsilon_scalingdye-probe scaling of the LJ parameters
Returns
RotamerScoreResult – uniform weights with partition 1.0 when a mask leaves nothing to score
Exceptions

Mean-field weights for several dyes at once, cross-interactions included.

The single-dye rotamer_mean_field_weights sees the protein only. With two or more labels on one structure each dye is also part of the others' environment, so the update carries a conformer-pair energy matrix per dye pair and iterates all of them together: , renormalised by log-sum-exp each round.

One per atom: 1 where the atom is masked out of a steric term.

The labelling site_residue (with site_chain, matched case-blind; -1 / empty mean no site) is always masked, so the dye is not sterically blocked by the residue it is attached to. mask_backbone additionally masks the backbone names (CA, C, N, O) – what the rotamer side wants and the protein side does not.
