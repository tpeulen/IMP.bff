Detailed Description

A score from plain functions, for C++ callers that build a graph from closures.

Not wrapped for Python (a Python caller subclasses InferenceFactorScore).

◆ get_score_type()

std::string InferenceFunctionScore::get_score_type ( )
inlineoverridevirtual

The registered type that rebuilds this score from get_score_document(); empty if it cannot be written.

A graph saved with its data (InferenceFactorGraph::save with embed_data) writes each score as this type and document; loading calls the factory registered under the type (register_factor_score, registry capability factor_score). Scores that return the same type and the same document bytes are written once and rebuilt by one factory call (PRD-156).
