Detailed Description

A cooperative stop for a run that may take minutes.

Subclass it (in C++ or, through the director, in Python) and answer true to end a run early, keeping the pose reached. It is asked between chunks of optimisation and not inside the optimiser's own callback, because raising out of an IMP::OptimizerState mid-step is not reliable.
