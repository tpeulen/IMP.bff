76 // ---- IMP::bff::ProbeSimulation: the shape every simulation shares ----
77 //
78 // The walk is one particle on a grid, so `get_n_atoms()` is 1 and the
79 // positions are its own. It has no energy and no minimiser, and says so
80 // rather than returning a polite zero. `run()` drives #simulate() with
81 // the parameters in force, taking `n_steps * t_step` as the time to
82 // cover; `write_every` thins the record the walk already produces.
