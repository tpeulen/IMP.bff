Record one episode: one row per move, flattened, and the correct move.

priors are the moves' declared priors, one per row. Training scores a move as log(prior) + network(row), exactly as a search weights it, so the network learns a correction to what the family declares.

Exceptions
ModelSearchConfigurationErrorunless every row has get_policy_state_width() + get_policy_action_width() features and label indexes one of them.
