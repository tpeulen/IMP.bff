Detailed Description

A benefit per candidate pair: the chance that a selected pair sees a change.

Each candidate pair carries a probability d_p in [0, 1] that its distance changes between conformations, for example from an elastic network (#IMP::bff::get_pair_change_probabilities). The loss is the probability that no selected pair sees a change,

1 with nothing selected, as for the resolution and kinetics terms, and falling with every pair likely to report a change. A pair whose probability is NaN is not eligible. Pair-level only: in site mode each pair a new site implies counts.
