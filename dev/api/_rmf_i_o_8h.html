Write (N, 3) coordinates to an RMF file as one frame of spheres.

Each row becomes a particle with an #IMP::core::XYZR and an #IMP::atom::Mass, under one hierarchy root – enough for a viewer to open the file and for #IMP::rmf to read it back.

Parameters
[in]coords,n_atoms,n_dimthe positions, (N, 3)
[in]paththe file to write
[in]model_namenames the hierarchy root
[in]metadata_jsonrecorded as the file's description; a caller with a dict passes json.dumps of it. Empty writes no description.
[in]radiusof every sphere, Angstrom
Exceptions
ValueExceptionwhen n_dim is not 3

◆ write_rotamer_library_rmf()

IMPBFFEXPORT void write_rotamer_library_rmf ( const std::string & path,
const ProbeRotamerLibrary & library )

Write a rotamer library to an RMF file, one frame per conformer.

The weight of a conformer is a per-frame value in the score category; the jump counts, when the library has them, are one static Ints value in the kinetic category. Both are what #IMP::bff::read_rotamer_library_rmf reads back.

Parameters
[in]paththe file to write; .rmf3 is appended when missing
[in]librarythe conformers, their weights and their atom names
Exceptions
ValueExceptionwhen the library has no conformers, or its coordinates do not match n_rotamers * n_atoms * 3
