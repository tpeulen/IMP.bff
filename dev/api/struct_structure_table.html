Detailed Description

A coordinate file as parallel columns, one entry per atom.

Every column has the same length, get_n_atoms, except xyz which has three entries per atom. An application builds its record array by assigning the columns; nothing here is IMP-shaped, so nothing has to be walked one atom at a time on the Python side.
