How many residues of each type are near every voxel of a volume.

Row r is the r-th occupied voxel (#IMP::bff::ProbeAccessibleVolume::get_voxel_indices order), column t the residue type residue_types[t]; the entry counts the residues of that type – keyed (chain, res_id, res_name), as #IMP::bff::residue_sites groups them – whose slow centre (CB, else CA, else the residue's first atom) lies within radius of the voxel.

The geometry is the stickiness stamp's, exactly: a centre is floored onto a voxel in the walk frame (#IMP::bff::center_grid_indices with #IMP::bff::ProbeAccessibleVolume::get_walk_anchor) and a voxel is within reach when its index offset satisfies . So a residue type's slow factor map with factor equals voxel by voxel; this returns the exponents, one stamp per type rather than one map per type, which is what an equilibrium ensemble over many stickiness sets needs.

Parameters
[in]avthe volume; its density decides which voxels are rows
[in]atomsthe structure, as the quenching model takes it
[in]residue_typesresidue names, upper case, one column each
[out]out_matrix,n_out_rows,n_out_cols(n_voxels, n_types) int32
[in]radiusAngstrom
