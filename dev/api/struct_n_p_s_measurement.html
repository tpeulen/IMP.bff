◆ eff_conv_coeff

std::vector<std::vector<double> > NPSMeasurement::eff_conv_coeff

Distance-convolution coefficient rows (12 coefficients each). Which row a measurement uses follows the dye models: row 0 for an iso/iso pair, the 625-entry pair orientation grid for a non-iso/non-iso pair, the 25-entry single-dye grid for a mixed pair, indexed by nps_orientation_row_index() and nps_single_orientation_row_index().
