Direct information for pairs of structure residues.

Maps each residue to the alignment column whose reference residue is residue - residue_offset, and returns the direct information of the two columns; NaN when either residue has no column (a #IMP::bff::ProbePairCostTerm treats NaN as ineligible). The alignment's reference must be the structure's sequence; residue_offset is the structure's number of the residue before the first one of the reference.

[in]coevolutionthe analysis
