enum FitNoiseFamily

How the variance of a measured value is known.

Enumerator
FIT_NOISE_FAMILY_POISSON 

Counts. , the model's own prediction.

FIT_NOISE_FAMILY_STORED 

A measurement with its own per-point variance, supplied with the data.

FIT_NOISE_FAMILY_CONSTANT 

Gaussian with one variance for every point.

FIT_NOISE_FAMILY_PROPAGATED 

A variance carried here by propagation from other datasets.

Set by #set_linear_combination, and stored rather than derived from the model for the reason given there: the components' own predictions are not recoverable from the combination.
