Detailed Description

One dye's photophysics, declared as data.

Named states with, per state, a relative excitability (absorption at the excitation wavelengths, 0 for a bleached or dark-absorbing state), a fluorescence quantum yield, a fluorescence lifetime (ns), and whether it accepts energy by FRET (0..1, scales R0^6; acceptor only). Transitions between states are rates; a light rate is multiplied by the measurement's excitation power (triplet formation, photobleaching, photo-isomerisation). A rate may be conditioned on the hidden state (PET quenching only in some conformers), which makes the hidden process a parent of the dye in the KineticNetwork.
