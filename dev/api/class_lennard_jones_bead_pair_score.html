Detailed Description

Truncated Lennard-Jones between two beads with one equilibrium distance.

with : the (6,12) well in its form, with no – the restraint's weight is the depth. What chisurf called the "LJ bead" potential over C-alphas.

Unlike #IMP::atom::LennardJonesTypedPairScore this needs no types and no force field: one distance for every pair, which is what a one-bead-per- residue model has.
