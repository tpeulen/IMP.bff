IMPBFFEXPORT void write_av ( const ProbeAccessibleVolume &  av,
const std::string &  path 
)

Write a volume to path; the format follows the file extension.

The overload for the value type #IMP::bff::get_av() returns, so the array front door and the decorator front door are written the same way.

extension what is written
.xyz the point cloud, weight in a fifth column
.pqr the point cloud, weight in the charge column
.dx the density grid, as OpenDX
Parameters
[in]avthe volume
[in]paththe output path, whose extension picks the format
Exceptions
ValueExceptionon an unknown extension, or on a grid format when the volume carries only a cloud
IOExceptionwhen path cannot be opened
