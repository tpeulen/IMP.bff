Detailed Description

One probe and the site it goes on.

Note
The hierarchy and the transformation are held privately and handed out by value. They are IMP value types, and a public member of one would have SWIG return a non-const reference to it, which IMP's wrapper layer refuses – for the good reason that a caller mutating it would be editing this object's insides through a borrowed handle.
