Detailed Description

What one column of a tabular artifact holds.

Carried with the column rather than with the file, so a caller reading two columns out of a large table still learns what they are. Units are a _mmfdb_column.units term: no unit means the unit is unknown, and dimensionless is a positive claim for a ratio that genuinely has none.
