Detailed Description

Evaluates the internal LJ energy of dye conformations.

The pair list is every non-excluded site pair of system (see get_lj_pair_sites), so bonded neighbours do not sterically block each other. evaluate takes one frame; evaluate_batch one per frame; evaluate_batch_filtered pre-filters with a BoundingBoxFilter and gives non-overlapping frames zero energy.
