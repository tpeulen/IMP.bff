Detailed Description

What a pair geometry transfers, in the three averaging limits.

static_ averages the per-pair efficiency; dynamic1 uses the ensemble and then averages; dynamic2 averages the rate* and converts once. They differ by which quantity the ensemble is fast compared with, and reporting one under another's name is a common way to be wrong by tens of percent.
