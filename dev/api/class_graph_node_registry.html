◆ Factory

typedef std::function<std::shared_ptr<GraphNode>(const std::string& name)> GraphNodeRegistry::Factory

Builds one ready node: constructed, owned, and with its ports built.

Ports attach to their node through a weak_ptr, so a node that owns ports can only build them once a shared_ptr holds it. A factory returning an owned node is therefore the only correct shape; see FRETSpectrumNode::build_ports().
