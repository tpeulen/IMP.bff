Detailed Description

One residue, and where its atoms are in the flat arrays of LabelizerStructure.

The backbone indices are resolved once, at read time, because every kernel below wants them and each would otherwise re-scan the atom list. A missing atom is -1 and stays -1: a residue without a CA cannot be scored, and substituting a neighbouring atom yields a plausible, wrong answer.
