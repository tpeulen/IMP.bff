Detailed Description

Metropolis sampling of a dye's linker, and the library it makes.

(formerly IMP/bff/LinkerSampling.h, now a section of this file)

A dye on a protein is a chromophore on a flexible tether, and what the tether can do is a handful of torsions and bond angles. Sampling those – rather than every Cartesian degree of freedom – is what makes a rotamer library cheap enough to build per dye.

Note
There is no IMP model here. Sampling reads and writes plain coordinate arrays: routing each trial configuration through IMP::core::XYZ decorators would cost thousands of boundary crossings per step for coordinates #IMP::bff::LinkerGeometry::apply has just returned.
