Detailed Description

An ESM-2 protein language model, loaded from GGUF; cheap to copy, safe from many threads.

Residue contact probabilities, n x n (n residues, at most get_max_length): ESM's contact head, a logistic regression over the symmetrised, average-product-corrected attention maps of every layer and head (Rao et al., ICLR 2021). From the single sequence, no MSA.
