Detailed Description

The eigen-decomposition of a real symmetric tridiagonal matrix.

Eigenvalues are sorted in descending order. get_vectors() is row-major n x n with the eigenvectors in the columns: element [i*n + k] is component i of eigenvector k, so T = V diag(values) V^T.
