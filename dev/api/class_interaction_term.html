How many participants the term is defined over.

1 for a process of the dye alone, 2 for a pair, more for a genuinely many-body process.

True when the term needs transition dipoles.

A caller can then tell whether a representation without them (an accessible volume) forces an isotropic assumption instead of resolving the orientation.
