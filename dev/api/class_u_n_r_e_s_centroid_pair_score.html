Detailed Description

UNRES side-chain centroid contact energy between two centroids.

A distance-binned energy per residue-type pair – the GBV side-chain potential – which is IMP::core::StatisticalPairScore exactly. The repulsion below min_dist and the clamp above max_dist are in the table: the bins below the minimum hold the penalty and the bins above the last measured distance repeat it, so the behaviour is the data's and not a branch in a loop.

The shipped table is in kcal/mol; multiply the restraint's weight by 0.593 for kT at 298 K, which is what chisurf's CEPotential did.
