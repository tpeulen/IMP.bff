Probability that each pair's distance changes by more than 5 Å between states: the calibrated logistic in the pair's fluctuation relative to the structure's own (see the file description).

Usable as the per-pair probabilities of a #IMP::bff::ProbePairBenefitTerm.

Parameters

[in]pairs,n_pair_rows,n_pair_colstwo point indices (0-based) per pair

Returns
a probability per pair; NaN for an invalid pair
