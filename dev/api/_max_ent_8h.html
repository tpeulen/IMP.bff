Maximum-entropy inversion of a linear model.

Minimises sum_i w_i (A x - b)_i^2 - nu^2 S(x; prior) over x >= 0.

Parameters
[in]designA, n_rows x n_cols, row-major
[in]measurementsb, length n_rows
[in]weightsw (1/sigma^2 per row); empty weights every row 1
[in]priorlength n_cols, strictly positive; empty is uniform

Maximum entropy under a quadratic chi-square.

chi^2(p) = 1/2 p^T H p - g^T p + chisq_constant, maximised against the entropy relative to prior (strictly positive; the entropy peaks at p = prior) with weight nu; nu = 0 is the bound-constrained least squares solution.

Parameters
[in]hessiann x n, row-major
[in]gradientthe linear term g, length n
[in]priorlength n
[in]max_iter,tol,min_probthe iteration cap, the tolerance on the gradient angle, and the positivity floor
