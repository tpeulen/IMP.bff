Detailed Description

Structural resolution: Olga's expected RMSD.

The loss is the expected mean RMSD between the true frame and the one the measurements would pick (#IMP::bff::expected_rmsd), divided by its value before any measurement. The degrees of freedom follow Olga: while choosing, max(n + n_new - 2, 1) for n measurements made and n_new added by the candidate; for the loss of what was chosen, max(n, 1). Those are the conventions of #IMP::bff::select_probe_pairs and #IMP::bff::select_probe_positions, so this term alone reproduces them.
