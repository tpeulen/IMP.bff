Detailed Description

The hidden conformational process shared by every measurement.

Either K discrete conformers with a rate matrix, or a free-energy landscape u(q) (kT, natural cubic spline on uniform knots) with diffusion coefficient D over a path coordinate q, discretised on a uniform grid by SqRA (FRETLandscapeGrid.h). Start distribution: the stationary distribution (Boltzmann on the grid for a landscape).

◆ set_reversible()

void FRETHiddenProcess::set_reversible ( bool reversible)

Discrete: switch the parameters to populations and exchange fluxes, a reversible chain by construction. The current rates are converted: pi is their stationary distribution and, per connected pair i < j (both rates > 0), s_ij = (pi_i k_ij + pi_j k_ji) / 2. Afterwards k_ij = s_ij / pi_i with pi = w / sum(w) from unnormalised weights w; the parameters are population[k] (log w, one scale gauge left to a prior or a fixed weight) and flux[i-j] (log s), so Gaussian priors on them are an MSM's population and flux priors (prototypes/fret_network_landscape/ensemble_prior.py). false converts back to the rates.
