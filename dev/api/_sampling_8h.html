IMPBFFEXPORT std::unique_ptr< SamplerKernel > create_sampler_kernel ( const std::string & name_or_alias,
const std::string & options_json = "{}" )

A kernel by registry name or alias (category sampler), configured from JSON options.

Options are checked against the entry's params_schema before the kernel sees them: an undeclared key, a value of the wrong type or outside minimum/maximum is refused with the option's own description in the message. Compiled (src/Sampling.cpp): the registry is in the library.
