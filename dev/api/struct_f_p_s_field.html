◆ default_json

std::string FPSField::default_json

The value a reader may assume when the key is absent, as JSON text.

Empty means no default: the key is then required for the dialects in dialects. "null" is not used — an absent default is the empty string, so that a field whose default really is JSON null stays expressible.
