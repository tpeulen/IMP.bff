Detailed Description

2-body: Förster transfer between two dyes.

R0 is derived, not supplied** — from the two dyes' spectra, the donor's quantum yield, the medium's refractive index and . Passing it in was how forster_radius=52.0 came to be a default in a dozen signatures.
