Detailed Description

An atom's name as its structure spells it, without a HET: prefix.

IMP names a heteroatom HET: C3 ; every reader in this module wants C3. It was written out three times in three files before it was written down once here.

Names of every XYZ leaf, in the same order as hierarchy_atom_coordinates. One frame of a structure: coordinates and the labels that identify atoms.

What the rotamer scorer needs of a protein and no more, as six parallel arrays. A frame is one model of a multi-MODEL PDB, or one frame of a trajectory.
