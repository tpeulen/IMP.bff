The donor decay with the radiative lifetime included.

, the sum propagated with the rate map as the sink, by Lanczos (run_krylov()) – so t_step is only the report spacing. The start is the solver's density, or the stationary occupancy when that is empty: an ensemble excited out of its equilibrium.

Propagate with no decay until the occupancy stops moving.

Prefer equilibrium_occupancy(), which is the same answer in closed form. This iterates toward it, and on a real site – where D spans orders of magnitude through the compounding slow factor – it can fail to converge in any practical number of steps.

GridDiffusionGradient GridDiffusionSolver::gradient ( const std::vector< double > & dL_dF,
int n_steps,
int n_out,
const std::vector< double > & density )

Adjoint of run(): the gradient of a loss on the decay, every voxel at once.

For , returns dL/dD, dL/dk and dL/dp0 for about four times the cost of one run(). Finite differences need one run per parameter.

The gradient is of the discrete scheme actually run, so it agrees with a central difference of run() to roundoff – which is also why the time step must not depend on the parameters being differentiated.

Parameters
[in]dL_dFsensitivity of the loss to each reported population
[in]densitythe start of the run being differentiated; run() replaces the solver's own with the final one, so a completed run has to be handed the density it began with
Returns
a GridDiffusionGradient of dL/dD, dL/dk and dL/dp0, per voxel

◆ run_krylov()

GridDiffusionResult GridDiffusionSolver::run_krylov ( int n_steps,
int n_out = 1,
int krylov_dim = 128 ) const

The same propagation as one matrix exponential (Lanczos), no stepping.

The semi-discrete solution at the times run() would report, n_steps / n_out + 1 of them, in krylov_dim operator applications instead of n_steps sweeps, and with no stability limit on t_step (which only sets the report grid). It agrees with run() to the stepping scheme's own error. Advances get_n_iterations() by nothing and leaves the density alone.
