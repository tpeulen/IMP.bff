◆ FRETArrivalModel

enum FRETArrivalModel

How photon arrival times enter a measurement's likelihood.

Enumerator
FRET_ARRIVAL_FULL 

Killing between photons with Lambda_tot(s): the count rate is information. Valid when each state's brightness is constant (immobilised molecules, the paper's traces).

FRET_ARRIVAL_CONDITIONAL 

Arrival times taken as given (Gopich-Szabo / H2MM): between photons the generator alone, each photon the normalised probability of its channel and microtime, E_c(t|s) / Lambda_tot(s). Insensitive to the brightness modulation of a molecule crossing the focus; the default for bursts.
