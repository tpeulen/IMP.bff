IMPBFF_BEGIN_NAMESPACE IMPBFFEXPORT bool register_algorithm_json ( const std::string &  capability,
const std::string &  key,
const std::string &  entry_json 
)

Register one entry under capability / key from its JSON object.

The entry is what registry(capability)[key] shows; see RegistryCore.h for the keys read from it. provider defaults to "imp.bff".

Returns
false when the entry is not a JSON object or key is taken – a duplicate is refused, never overwritten, so the result cannot depend on load order.
