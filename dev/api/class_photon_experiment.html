Record the counts an instrument collects for an expected micro-time curve.

An immobile emitter whose decay is expected is observed until Poisson(sum(expected)) photons have arrived, one micro-time channel per bin. The result is the histogram TTTRLib's encoder produced – counting noise and all – rather than a noise model applied to the curve.
