Detailed Description

One ATOM/HETATM record: where it is, how big, and what names it.

Every field a reader in this package wanted of one. There were two such records until 2026-08-20 — this one, and a serial/element-carrying twin the MOL2 writer used — with two parsers behind them, only one of them cached.
