Detailed Description

An ensemble of conformers with a weight each: a rotamer library.

The conformers may be a dye's rotamers, a spin label's, a side chain's or the frames of a trajectory that was clustered into one – the value says nothing about which, because nothing that reads it needs to know.

◆ metadata

std::string ProbeRotamerLibrary::metadata

The registry entry for this library, as JSON, or {} when it has none.

The dye's selectors – which atoms are the chromophore centre, which two span the transition dipole, which carry charge – are here and not in the coordinates, so a library read from an off-registry path has an empty object and its caller supplies them.

◆ transitions

std::vector<int> ProbeRotamerLibrary::transitions

Jump counts between conformers, flat n_rotamers * n_rotamers.

Empty unless the library came from a run that saw the conformers in order* – a Metropolis trajectory, a molecular-dynamics one – because only then is there such a thing as a jump. A library read from a container of static conformers has none, and that is not a defect.
