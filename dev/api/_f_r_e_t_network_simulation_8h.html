double  max_gap,
int  min_photons 
)

Burst selection by interphoton time.

A burst is a maximal run of photons inside one input segment whose consecutive gaps are all at most max_gap, kept when it has at least min_photons. Returns the same photons with the bursts as segments (photons outside every burst stay in the arrays, in no segment).
