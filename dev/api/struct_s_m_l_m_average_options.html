◆ normalize_density

bool SMLMAverageOptions::normalize_density = true

Divide by accepted particle count (above) or accepted total weight (below).

Half maps use their OWN denominators. False returns the weighted sum. Maps are continuous densities, not voxel probabilities; integrate with spacing[0]*spacing[1]*spacing[2]. Clipped tails are not redistributed.
