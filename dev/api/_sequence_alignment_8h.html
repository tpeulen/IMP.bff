The bundled fluorescent-protein library (data/cgprobe/fp_library.json).

A copy of fpsim's registry, as JSON text. fpsim is the home of this algorithm; the copy exists so imp_bff dye label-fp works without it, and the drift between them is tracked in chisurf PRD-96. Do not extend it here.

Which fluorescent proteins a fusion sequence contains, and where.

Each library entry is looked for twice over: first by its motifs, which narrows the search to a window around the match and makes the alignment cheap, and otherwise by aligning the whole sequence. Hits are taken best identity first and a hit overlapping one already taken is dropped – a residue belongs to one domain.

Parameters
[in]sequencethe fusion's one-letter sequence
[in]min_identitybelow this a hit is not a domain
Returns
one segment per domain, kind fp, in the order taken

Cut a sequence into rigid cores, linkers and fluorescent proteins.

A residue is rigid when its pLDDT reaches rigid_threshold, and a detected fluorescent protein is rigid whatever its pLDDT says. A rigid run shorter than min_rigid_length becomes linker: a handful of confident residues between two linkers is not a body that can be moved as one.

Parameters
[in]sequence_lengthhow many residues
[in]plddtper-residue scores (parse_plddt_from_pdb)
[in]fp_domainswhat get_fp_domains found
[in]rigid_thresholdthe pLDDT a rigid residue reaches
[in]min_rigid_lengththe shortest run that stays rigid
Returns
the segments, in sequence order, covering every residue

Smith-Waterman local alignment with affine gaps, Gotoh's formulation.

Three matrices: one for a residue pair and one per sequence for a gap continuing in it, which is what makes an affine penalty exact rather than a per-position approximation. Replaces Biopython's PairwiseAligner in local mode with the same scoring, so imp.bff needs nothing beyond what IMP brings.

Returns the aligned blocks in ascending order, in the spelling Biopython's aligned uses.
