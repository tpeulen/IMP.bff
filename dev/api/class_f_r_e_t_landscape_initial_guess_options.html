Detailed Description

How FRETLandscapeModel::initial_guess() starts a fit from the data.

Paper Sec. III C: photon rates from the count rates, backgrounds at their prior means, the landscape by Boltzmann inversion of a kernel density of binned-photon distances, the bin width by held-out likelihood, and D by a coarse grid search.
