Detailed Description

One labelling position as a particle an MD engine can move.

What Olga writes into an AMBER restart file as a dummy atom, here as an IMP particle: an XYZR with a mass, tethered to its attachment atom by a stiff harmonic bond at the offset the volume itself has, so it follows the site as the structure moves. The FRET restraints are then ordinary two-particle restraints between these.

Note
There is deliberately no offset here. The tether length is a live quantity – IMP::bff::AVRebuildOptimizerState moves it when it rebuilds the volumes – and it is held in one place, the tether itself. Ask IMP::bff::MDRestraintSystem::get_tether_length().
