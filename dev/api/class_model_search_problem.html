Detailed Description

Model-specific topology and evaluation, implemented entirely in C++.

evaluate() may return a key different from the action's predicted key. This is how an optimiser reports that a nominally larger model collapsed onto a canonical ancestor. The tree records its reward, then makes that node a dead end so the collapsed structure is not searched repeatedly.
