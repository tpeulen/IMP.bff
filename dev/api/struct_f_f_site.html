std::string FFSite::element

Chemical element, which is what picks the site's LJ type.

Present because the two producers of this structure disagreed about it: the mmCIF reader set site_no and no element, the topology builder set an element and no site_no, and read_dye_forcefield_cif guarded with s.get("site_no") because it might not be there. One type, one shape.
