Detailed Description

A cost per candidate pair: the chance that a selected pair is a problem.

Each candidate pair carries a cost c_p in [0, 1], read as the probability that measuring it causes a problem the other terms do not see, for example that its two sites co-evolve, so mutating both may disturb the coupling under study. The loss is the probability that at least one selected pair is a problem,

0 with nothing selected, growing with every costly pair, never above 1, and without a budget to set. A pair whose cost is NaN is not eligible. Pair-level only: in site mode each pair a new site implies is charged.
