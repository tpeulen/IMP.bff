Detailed Description

Propagate an excited-state density on a masked 3-D grid.

Parameters
densityinitial occupancy, flat ng^3
boundsnon-zero inside the accessible volume
diffusion_mapper-voxel D, A^2/ns
rate_mapper-voxel deactivation rate, 1/ns
dgvoxel edge, A
t_steptime step, ns
flux_formFLUX_SMOLUCHOWSKI or FLUX_ITO
check_stabilityrefuse a step past the explicit scheme's limit The donor decay run() leaves behind.

A value carrying the time axis, the surviving excited-state fraction at each reported step, and the final density. Its arrays are read back as managed numpy views through the get_*() methods (ARGOUTVIEWM_ARRAY1), so a caller treats result.get_time(), result.get_fluorescence() and result.get_density() as ndarrays.
