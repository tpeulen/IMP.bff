Detailed Description

The Ramachandran pseudo-energy of a chain's backbone dihedrals.

from C(i-1), N(i), CA(i), C(i) and from N(i), CA(i), C(i), N(i+1); the first residue has no and the last no , and both are skipped. Each residue's is read out of a grid as , so a uniform map scores zero. A map whose values never go positive is taken to hold pseudo-energies already and is returned negated.

chisurf's class of this name returned 0.0 and logged a warning – the C function it called had been lost. This is the imp-tricks implementation.
