◆ minimizer_reported_total()

IMPBFFEXPORT int minimizer_reported_total ( int nfev,
int expected )

The total to report nfev against, so a progress bar always moves.

chisurf's _reported_total. The reported fraction is asymptotic, 0.99 * (1 - 2^(-nfev / (2 * expected))), because a linear bar against a guessed total saturates on exactly the fits long enough for anyone to be watching – a real MFD fit takes 450 evaluations against an estimate of 42, and sat at 98-99% for 91% of its runtime.
