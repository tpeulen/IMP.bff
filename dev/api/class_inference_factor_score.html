Detailed Description

The numbers of a factor: what makes a structural factor evaluable (PRD-155).

A factor of InferenceFactorGraph is a term of the log posterior over its scope. A score computes it. x is the factor's scope values in scope order, each variable contributing size numbers from the flat parameter vector (positions index .. index + size - 1); n = x.size().

eval() returns [log p] without derivatives, and with them [log p, d log p / dx (n), I (n x n, row-major)], where I is the factor's information: a symmetric positive semi-definite stand-in for minus the Hessian (the expected information of a likelihood, minus the Hessian of a Gaussian prior). The generic fit (inference_fitting) steps with the sum of the factors' I, which is Fisher scoring when every factor gives its expected information.

predict() and get_data() are optional: what the factor expects its data to be at x and the data themselves, aligned, so a caller can form residuals without knowing the model. Both empty when the factor has no data (a prior).

Subclass in C++, or in Python (a SWIG director), for any model; the graph never knows which model a factor belongs to. Written 2026-11-10 by claude-code/Opus 5.5 for tpeulen.
