Detailed Description

Raised for a misconfigured minimiser (no objective, fixed ports, a bounds list that does not match the parameters...).

std::domain_error so the wrapper maps it to a ValueError, which is the contract chisurf's optimiser raises under – the same choice MCMCSamplerConfigurationError and GraphLinkCycleError make.
