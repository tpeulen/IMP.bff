Detailed Description

Running (Welford) mean and covariance – full or diagonal – of the draws in a metric window, with Stan's regularisation (welford_covar_estimator / welford_var_estimator + covar_adaptation / var_adaptation): n/(n+5) S + 1e-3 5/(n+5) I. PRD-147 A3.
