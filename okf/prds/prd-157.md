# PRD-157: the kappa^2 surrogate in bff

## What tpeulen asked (verbatim, 2026-11-12)

> "in dev playgourn k2dist you find surrograt mdl for k2 distirbuiton, integrate into bff, if not
> already integrated, the surrogates are much faster. once intgerated make chisurf use surrogate
> mdl. also add script for trainign of surrogate, use bff for training. ship pretrained nn. bff
> should use own nn."

## What exists (checked 2026-11-12)

* **Prototype** `~/dev/playground/k2dist/k2_surrogate_tain_inf.py` + `k2_hist_nn.npz`: two
  independent, isotropically diffusing dipoles (Brownian rotation, P1 correlation time tau1,
  r-hat fixed); kappa^2 averaged over a window T; histogram over kappa^2 in [0, 4] (120 bins).
  Network: log10(T) -> 64 tanh -> 64 tanh -> 120 logits -> softmax, trained in torch with the
  cross-entropy between target and predicted histograms (700 epochs, Adam 2e-3), 600 simulated
  cases x 6000 trajectories, dt 0.05 ns, **tau1 fixed at 16 ns, T in [1e-3, 10] ns** -- so it
  covers T/tau1 in [6e-5, 0.63] only, and its input is log10(T) at that one tau1.
* **bff** has kappa^2 for geometry (`kappa2_dipole_matrix`), static isotropic dipoles
  (`isotropic_kappa2_density`), wobbling-in-a-cone (`wobbling_kappa2_distribution[_delta]`, Sindbert
  2011) and a trap sampler (`sample_kappa2_diffusion_with_traps`) -- **not** the time-averaged
  distribution of rotating dyes, and no surrogate. So: not integrated.
* bff's `NeuralNet` (msgpack documents, tanh layers, `from_safetensors`, reverse pass for any
  loss) and `train_neural_net` (Adam, a regressor with a linear output and squared loss).

## Design

* **The physics in C++** (what can be C++ must be C++): `simulate_time_averaged_kappa2(T_over_tau1,
  n_traj, dt_over_tau1, seed)` -- the prototype's Brownian two-rotor simulator in reduced units
  (only T/tau1 matters for free isotropic rotation), and its histogram on the shipped bins.
* **The surrogate**: a `NeuralNet` (bff's own) mapping log10(T/tau1) to the 120 logits; one
  function `time_averaged_kappa2_distribution(T, tau1)` returns bin edges and probabilities
  (softmax of the logits), refusing T/tau1 outside the trained range (no extrapolation). Shipped
  as a msgpack document in bff's data, found through the registry (capability e.g.
  `kappa2_distribution`, beside the cone and static forms), so ChiSurf discovers it.
* **Training in bff**: a training program that simulates with the C++ simulator and trains with
  bff -- the cross-entropy loss through `NeuralNet`'s reverse pass and Adam (the prototype's
  loss; `train_neural_net` is a squared-loss regressor, so the training loop uses the reverse
  pass), written as a script under `examples/` or a `bin/imp_bff` subcommand; reproducible seed;
  writes the msgpack document and a validation figure (simulated vs predicted histograms on
  held-out T, the per-case total variation).
* **Pretrained network shipped.** First the prototype's weights converted to bff's document
  (in reduced units: log10(T/tau1) = log10(T) - log10(16)) with a parity test against the
  prototype's NumPy forward pass; then the network retrained with bff over the full range a FRET
  measurement needs (T = donor lifetime window, tau1 from fast to slow rotation: T/tau1 from
  ~1e-3 to ~1e2, approaching the dynamic delta at 2/3), declared before training, validated
  against fresh simulations.
* **ChiSurf** uses the surrogate where it computes kappa^2 distributions (the kappa^2 controls of
  its FRET models, `chisurf/emtk/model_sections.py` kappa^2 regime): a "time-averaged (rotating
  dyes)" choice calling bff.

## Steps (each: done when)

1. **This PRD**, committed alone.
2. **C++ simulator** `simulate_time_averaged_kappa2`. Done when: isotropic limit T/tau1 -> 0 gives
   the static isotropic density (`isotropic_kappa2_density`, KS distance below a declared bound),
   T/tau1 large gives a narrow distribution at 2/3 (mean 2/3 within 3 standard errors), and the
   prototype's NumPy simulator at three T values agrees in histogram (total variation below a
   declared bound with its sampling noise measured).
3. **Prototype weights as a bff NeuralNet** (msgpack) + `time_averaged_kappa2_distribution`.
   Done when: equal to the prototype's NumPy forward pass to 1e-6 on 100 inputs; outside the
   trained range refused.
4. **Training program in bff** (cross-entropy via reverse pass + Adam). Done when: retraining the
   prototype's setting reproduces its held-out loss within a declared margin; the run writes the
   document, a loss curve and the validation figure.
5. **Pretrained network over the declared full range**, shipped in bff data, registered. Done
   when: held-out simulations within the declared total-variation bound across the range; speed
   measured against simulation.
6. **ChiSurf** uses it (kappa^2 regime choice). Done when: the FRET model's kappa^2 distribution
   comes from the surrogate in ChiSurf, with a test.
7. **Wheels** rebuilt (data file included).

## Open (scientific, tpeulen)

* The prototype's physics is free isotropic rotation (no cone, no residual anisotropy). The
  ucfret kappa^2 bands use the cone model from residual anisotropies (old WebUI method). Whether
  the surrogate should also take order parameters (cone-restricted rotation) is a separate
  decision -- not in this PRD.
